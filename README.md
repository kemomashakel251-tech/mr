# منصة المستر — دليل التشغيل

منصة تعليمية بسيطة (HTML + CSS + JS خام، بدون فريمورك) مبنية على **Firebase** (الخطة المجانية Spark):
- **Firestore** لتخزين الكورسات، المدرسين، الطلاب، طلبات الاشتراك، محتوى الصفحة الرئيسية.
- **Authentication** لتسجيل دخول الطلاب والأدمن (بريد إلكتروني + كلمة سر).
- **Hosting** لاستضافة الموقع مجانًا.

## هيكل المشروع
```
index.html          الصفحة الرئيسية (عامة)
dashboard.html       لوحة الطالب (كورساته المفعّلة)
admin/index.html     لوحة تحكم الأدمن (تحكم كامل ديناميكي)
assets/css/          التصميم
assets/js/           كل منطق الموقع
firebase.json        إعداد الاستضافة
firestore.rules       قواعد الحماية
firestore.indexes.json
```

## 1) إنشاء مشروع Firebase
1. ادخل على https://console.firebase.google.com وأنشئ مشروع جديد (مجاني).
2. من **Build > Authentication > Sign-in method** فعّل طريقة **Email/Password**.
3. من **Build > Firestore Database** أنشئ قاعدة بيانات (اختر Production mode).
4. من **Project settings > General > Your apps** أضف تطبيق ويب (Web app) وهياخد لك كود `firebaseConfig`.

## 2) ربط المشروع بالكود
افتح الملف:
```
assets/js/firebase-config.js
```
واستبدل القيم (`apiKey`, `authDomain`, `projectId`, ...) بالقيم اللي هتاخدها من الخطوة اللي فاتت.

## 3) إنشاء حساب الأدمن
الأدمن هو حساب عادي في Authentication، بس لازم يتسجل في مجموعة `admins` في Firestore عشان ياخد صلاحية الدخول للوحة:

1. من **Authentication > Users** أضف مستخدم يدويًا (إيميل + كلمة سر) هيبقى هو حساب الأدمن.
2. انسخ الـ **UID** بتاعه من نفس الصفحة.
3. من **Firestore Database** أنشئ Collection اسمها `admins`، وجوّاها Document الـ ID بتاعه هو نفس الـ UID اللي نسخته (سيب المحتوى بأي حقل بسيط زي `role: "admin"`).

بكده تقدر تدخل على `admin/index.html` بنفس الإيميل وكلمة السر.

## 4) رفع قواعد الحماية (Firestore Rules)
لازم ترفع ملف `firestore.rules` لمشروعك عشان محدش غير الأدمن يقدر يعدل الكورسات أو بيانات الطلاب. أسهل طريقة:
- افتح **Firestore Database > Rules** في الكونسول، وانسخ محتوى `firestore.rules` والصقه، ثم Publish.

(أو باستخدام Firebase CLI لو عندك Node.js مثبت: `firebase deploy --only firestore:rules`)

## 5) رفع الموقع على Firebase Hosting (مجانًا)
لو عندك Node.js على جهازك:
```bash
npm install -g firebase-tools
firebase login
firebase init hosting   # اختار المشروع اللي عملته، والمجلد الحالي كـ public
firebase deploy
```
هيديك رابط زي: `https://your-project.web.app`

## 6) طريقة الاستخدام اليومية
- **الطالب**: يعمل حساب من الموقع → يشترك في كورس → يظهر طلبه في لوحة الأدمن تحت "طلبات الاشتراك" → بعد ما يتأكد الدفع (واتساب/فودافون كاش يدويًا) → الأدمن يضغط "تفعيل" → الكورس يظهر فورًا في لوحة الطالب.
- **الأدمن**: من `admin/index.html` يقدر يتحكم ديناميكيًا في: نص البانر الرئيسي والإحصائيات، إضافة/تعديل/حذف الكورسات ودروسها (روابط الفيديوهات)، المدرسين، آراء الطلاب، ومتابعة الطلاب المسجلين.

## ملاحظات عن الخطة المجانية
Firebase Spark (المجانية) بتدعم Authentication + Firestore + Hosting بحدود استخدام يومية سخية كفاية لمنصة تعليمية متوسطة الحجم. لو عدد الطلاب كبر جدًا هتحتاج تترقّى لخطة Blaze (تدفع بس على الاستهلاك الزايد عن الحد المجاني).

## أفكار للتوسع لاحقًا
- ربط بوابة دفع إلكتروني بدل التفعيل اليدوي.
- اختبارات/كويزات لكل كورس.
- شهادات إتمام تلقائية.
- تنبيهات واتساب/إيميل عند تفعيل الاشتراك.
